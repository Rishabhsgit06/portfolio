# 👋 Rishabh Shukla — Personal Portfolio

A personal portfolio website that presents my technical background, skills, projects, and journey in software development. It also features an AI-powered assistant that helps visitors explore my profile and learn more about my work.

## ✨ Features

- **Personal Introduction:** Presents my background, interests, and professional aspirations.
- **Project Showcase:** Highlights selected projects and practical development work.
- **Technical Skills:** Showcases my programming languages, development tools, and technical competencies.
- **AI-Powered Assistant:** Enables visitors to interact with an assistant designed to answer questions about my profile.
- **Responsive Interface:** Provides a consistent and accessible browsing experience across different screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🌐 Live Demo

[Explore My Portfolio](https://rishabhshuklasportfolio.netlify.app/)

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Rishabhsgit06/portfolio.git
   ```

2. Navigate to the project directory.
3. Open `index.html` in your browser.

If the AI assistant depends on external API credentials or a backend service, configure those separately according to the project's implementation.
